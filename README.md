# apex-coach-skills

APEX gameplay review skills for LLM-based coaching.

This repository stores coaching procedures, observation order, and review
format guidance. APEX-specific factual data belongs in `apex-reference-mcp`, and
video or audio extraction belongs in `game-video-analysis-mcp`.

## Skills

- [`skills/apex-combat-review/SKILL.md`](skills/apex-combat-review/SKILL.md)
  defines the baseline combat review flow.
